
# 🎵 Zingen

Uma landing page moderna desenvolvida para divulgar um aplicativo de karaokê, com foco em uma interface elegante, responsiva e rica em animações. O projeto foi criado para praticar conceitos avançados de HTML e CSS, proporcionando uma experiência visual envolvente.

## 📖 Sobre o projeto

O **Zingen** é uma página de apresentação (landing page) que destaca os principais recursos de um aplicativo de karaokê. A interface foi construída com ênfase em design moderno, organização do código e boas práticas de desenvolvimento Front-end.

Durante o desenvolvimento foram aplicados conceitos de responsividade, animações e componentes reutilizáveis, resultando em uma experiência fluida em diferentes dispositivos.

## ✨ Funcionalidades

* 🎤 Apresentação dos recursos do aplicativo;
* 📱 Layout totalmente responsivo;
* ✨ Animações e transições suaves;
* 🎨 Interface moderna e intuitiva;
* 🧩 Estrutura HTML semântica;
* ⚡ Componentes organizados e reutilizáveis.

## 🛠️ Tecnologias utilizadas

* HTML5
* CSS3
* Flexbox
* CSS Grid
* CSS Animations
* CSS Transitions
* Google Fonts

## 🚀 Como executar o projeto

1. Clone o repositório:

```bash
git clone https://github.com/jose-neres/Zingen.git
```

2. Acesse a pasta do projeto:

```bash
cd Zingen
```

3. Abra o arquivo `index.html` no navegador.

Também é possível visualizar a aplicação online através do GitHub Pages:

**[clicando aqui](https://jose-neres.github.io/Zingen/)**.

## 📱 Responsividade

O projeto foi desenvolvido seguindo a abordagem **Mobile First**, garantindo uma ótima experiência em smartphones, tablets e desktops.
